SHOP「A：店主屋台」 — 現行A vs A2（実例の定石を反映）

抽出した定石（実例から）

  1. 水平カウンター線(約40%)で分割。上=人/世界、下=品物。
  2. 店主は焦点1つ・やや左寄せ、品物の方を向く。
  3. 商品は下60%の棚ゾーン＝スクロール領域。増えても店主を潰さない。
  4. 通貨=右上固定／戻る=左上。四隅はシステム。
  5. カードは絵→名前→一言→価格→購入の固定順。購入ボタンが唯一のアクセント色。
  6. 重なりで奥行き（ひさし＞店主＞カウンター＞品物）。
  7. 棚ゾーンを面で囲って「在庫」と空を分離。
参考: Stardew(ピエール) / Cookie Run / ポケ森 / Hay Day の店主カウンター型。
